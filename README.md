# Mindfull Methods 🚀

A modern full-stack Internship SaaS Platform built using Next.js, TypeScript, Tailwind CSS, Supabase, and Vercel.

## 🌐 Live Demo

https://mindfull-methods.vercel.app

---

## ✨ Features

- 🔐 Authentication System
- 📊 Admin Dashboard
- 🧑‍💼 Internship Management
- ✏️ Full CRUD Operations
- 🔎 Search / Filter / Sorting
- 📱 Fully Responsive Design
- 🌙 Dark Mode Support
- ⚡ Real-time Supabase Database
- 📈 Analytics Integration
- 🚀 Production Deployment with Vercel

---

## 🛠️ Tech Stack

### Frontend
- Next.js 15
- React.js
- TypeScript
- Tailwind CSS

### Backend / Database
- Supabase
- PostgreSQL

### Deployment
- Vercel
