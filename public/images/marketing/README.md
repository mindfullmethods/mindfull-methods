# Marketing images

Replace these files to update the site without code changes. Paths are referenced in `src/lib/images.ts` and **Site & promos** (`/dashboard/admin/site`).

| File | Used on |
|------|---------|
| `hero.jpg` | Home hero background |
| `mentor-rajiv.jpg` | About page mentor portrait (also default in Site & promos) |
| `auth-collaboration.jpg` | Login / signup panels |
| `auth-dashboard.jpg` | Auth marketing panel alt |
| `dashboard-preview.jpg` | Home dashboard preview |
| `internship-fallback.jpg` | Internship cards without custom image |

**Tips:** Use WebP or JPG under ~400 KB. Mentor photo works best at **800×800** or **4:5** crop.

Course thumbnails live in `public/images/courses/{slug}.jpg`.
